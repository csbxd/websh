AI 操作契约与使用说明

所有操作和输出均为普通 DOM，可通过元素 ID、标签和文本读取，无需识别终端图像。

  1. 在 #command-input 填入命令，点击 #run-command。每次只提交一次。
  2. 读取 #session-status 和命令卡片的 data-status。执行中为 running，结束后读取退出码和输出。
  3. 输出在命令卡片的 data-stream="stdout" / data-stream="stderr" 文本节点内；退出码在 data-field="exit-code"。界面清理 ANSI，回车换行，其余控制字符转义。若 data-output-normalized="true"，精确原文保留在该卡片的 data-field="raw-output" JSON 中。
  4. 等待输入时使用 #stdin-input 与 #send-input。结束输入点击 #send-eof，停止命令点击 #interrupt-command。
  5. cd、变量和函数在当前会话中保留。需要独立环境时新建会话。命令没有伪终端；全屏交互程序应改用非交互选项。

运行时状态位于 #websh 的 data 属性、每张命令卡片以及下方 JSON。输出以文本显示；运行中自动更新。
